PÁGINA PARA MI AMORCITO

Para subirla a GitHub:
1. Borra el index.html viejo del repositorio.
2. Sube este index.html.
3. Sube también la carpeta imagenes con todas sus fotos.
4. Confirma con Commit changes.
5. Espera 1 o 2 minutos y actualiza la página.

Para editar textos después:
- Abre index.html en GitHub.
- Toca el lápiz.
- Cambia solo el texto.
- Pulsa Commit changes.
